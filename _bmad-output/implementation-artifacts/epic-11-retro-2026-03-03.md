### 业务成果

Epic 11 从零构建了完整的 AgentShell DSL，用户现在可以编写：

```
export TARGET=./src/auth.go
result = spawn '分析 $TARGET' --agent=code-analyst
if $result.exitcode == 0
  spawn '生成报告' | spawn '保存报告'
else
  spawn '记录失败' on-error spawn '告警'
end
```

支持管道链式执行、变量与环境传递、条件分支和内联错误处理——功能完整的智能体编排语言。

## 挑战与成长领域

1. **功能组合遗漏模式** — Code Review 连续三个 Story 发现组合路径遗漏：
   - 11.1: `runPipeline` 缺少 SIGINT 处理（HIGH）
   - 11.2: `handleExecScript` 进度事件缺少展开后的 Intent（MEDIUM）
   - 11.3: `executeBlock` 的 `StmtPipeline` case 未执行 `stmt.OnError` handler（MEDIUM）

   模式：主路径正确，但新功能与已有功能的组合路径被遗忘。Code Review 是最后防线，但应前移检查。

2. **进度计算近似值** — `countExecutableStages` 返回所有 if/else 分支的 spawn 总和上界，运行时只走一个分支，导致进度永远达不到 100%。已记录为 LOW 技术债，推迟至 Phase 3。

3. **上下文传播规范缺失** — 11.1 使用 `context.Background()` 不响应 daemon shutdown，反映了项目缺少明确的 context 传播编码规范。
