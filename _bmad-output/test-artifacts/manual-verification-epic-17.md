# Epic 17 手工验证指南：可视化调试面板（dashboard）

## 概述

本文档提供 Epic 17 所有 Story 的手工验证步骤，用于在自动化测试之外对功能进行端到端的人工确认。

## 前置准备

Dashboard 依赖 daemon 提供的实时进程数据（通过 IPC），离线回放模式除外。

```bash
# 1. 构建最新版本
make build

# 2. 启动一些测试智能体（确保 daemon 运行）
rnix spawn "向用户打招呼并介绍自己" --agent=greeter

# 3. 准备录制文件（用于 Story 17.5）
rnix spawn "分析当前目录结构" --agent=analyst --record
```

> **提示**：dashboard 实时模式通过 IPC 获取进程列表、syscall 事件和上下文 profile；离线模式通过录制文件加载。

## 关键注意事项

1. **Dashboard 需要 daemon** — 实时模式通过 IPC 获取数据，需要 daemon 运行
2. **离线模式无需 daemon** — `--load` 模式从录制文件加载，不连接 IPC
3. **NFR36** — TUI 刷新间隔 <= 500ms，10 并发进程 CPU <= 10%
4. **NFR37** — 支持 >= 50 进程节点无卡顿
5. **窗格联动** — 选中智能体节点时，时间线和热力图自动切换到对应数据
6. **全局操作键** — k/a/l/r 在非 tree 窗格中为全局操作；tree 窗格中 k 为向上导航
7. **事件分类着色** — LLM=蓝、Tool=绿、IPC=紫、VFS=黄、Error=红
8. **回放速率范围** — 0.5x ~ 8.0x，每次翻倍或减半
9. **敏感操作确认** — kill 操作需二次确认（y/N）
10. **状态消息 TTL** — 操作反馈消息约 2 秒后自动消失
