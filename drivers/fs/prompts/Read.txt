Reads a file from the local filesystem. You can access any file directly by using this operation.

Assume this operation is able to read all files within the process sandbox. If the user provides a path to a file, assume that path is valid. It is okay to read a file that does not exist; an error will be returned.

Usage:
- The file_path parameter must be a path relative to the process working directory
- By default, it reads the entire file. Very large files may be truncated with an overflow notice
- You can optionally specify a line offset and limit (especially handy for long files), but it's recommended to read the whole file first when feasible
- Results are returned with line numbers prefixed to each line (e.g., "1. ", "2. "). Use these line numbers when referencing specific locations in the file
- This operation can only read files, not directories. To list a directory, use Glob with pattern "*", or ls via Bash
- If you read a file that exists but has empty contents, you will receive a system notice in place of file contents
- If the file has not changed since the last read within this process, a brief stub is returned instead of re-reading the full content

This is a read-only operation that does not modify the file system.
