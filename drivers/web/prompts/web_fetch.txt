Fetch a URL and return its content as markdown. Use this tool to read web pages, documentation, API references, or any HTTP-accessible resource.

The tool will:
- Fetch the URL content via HTTP(S)
- Convert HTML to clean markdown
- Process the content with the prompt using a small, fast model when a prompt is provided
- Cache results for 15 minutes (same URL returns cached content)
- Automatically upgrade HTTP to HTTPS

Parameters:
- url (required): The URL to fetch
- prompt (optional): Describe what information you want to extract from the page. When provided, a secondary AI model processes the content with your prompt and returns a concise, focused response.

Notes:
- Returns markdown content truncated to 100K characters
- Results may be summarized if the content is very large
- Cross-domain redirects are reported but not followed automatically
- Use this for reading documentation, blog posts, API specs, or any web content
- For searching the web, use web_search instead
